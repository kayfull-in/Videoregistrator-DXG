Политика конфиденциальности

для мобильного приложения «Видеорегистратор DXG»

1. Общие положения

1.1. Настоящая Политика конфиденциальности (далее — «Политика») описывает, как мобильное приложение «Видеорегистратор DXG» (далее — «Приложение») обрабатывает и защищает информацию пользователей.

1.2. Используя Приложение, Пользователь принимает условия настоящей Политики.

2. Какие данные собирает Приложение

2.1. Приложение НЕ СОБИРАЕТ, НЕ ПЕРЕДАЁТ И НЕ ХРАНИТ какие-либо личные данные пользователей (имя, адрес, номер телефона, e-mail, геолокация и т.п.) на своих серверах.

2.2. Приложение НЕ ТРЕБУЕТ РЕГИСТРАЦИИ и не создаёт учётные записи пользователей.

2.3. Все видеофайлы и настройки хранятся ИСКЛЮЧИТЕЛЬНО ЛОКАЛЬНО на устройстве пользователя (в галерее и внутренней памяти) и никуда не передаются Правообладателю.

3. Доступ к камере и микрофону

3.1. Приложение запрашивает разрешение на использование камеры и микрофона исключительно для выполнения своей основной функции — записи видео. Без этих разрешений работа Приложения невозможна.

3.2. Приложение может работать в фоновом режиме (при выключенном экране) с использованием Foreground Service. Это необходимо для непрерывной записи, а также для того, чтобы минимизировать перегрев устройства и его аккумулятора, снизить износ и предотвратить повреждение от постоянного использования.

4. Передача данных третьим лицам

4.1. Приложение НЕ ПЕРЕДАЁТ никакие данные третьим лицам, за исключением случаев, указанных ниже.

4.2. Приложение использует рекламный сервис Яндекс.Реклама, который может использовать идентификатор устройства для показа рекламы. Яндекс.Реклама обрабатывает данные в соответствии с собственной Политикой конфиденциальности. Пользователь может отключить персонализированную рекламу в настройках своего устройства.

5. Безопасность и ответственность Пользователя

5.1. Приложение не имеет доступа к интернету для передачи видеофайлов (за исключением загрузки рекламного баннера).

5.2. Пользователь самостоятельно несёт ответственность за сохранность данных своего устройства, а также за законность производимой им съёмки (см. Пользовательское соглашение).

6. Изменение Политики

6.1. Правообладатель оставляет за собой право вносить изменения в настоящую Политику. Новая редакция вступает в силу с момента её публикации.

6.2. Пользователь обязуется самостоятельно отслеживать изменения в Политике.
